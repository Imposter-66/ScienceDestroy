# 地球破壊ゲーム

小学生の理科クイズ(3〜6年・全45問)に正解して、武器で地球をこわすゲームです。

## ファイル
- `index.html` … ゲーム本体。Publicキー(読み取り専用)だけが入っています。
- `server.js` … 書き込み用の中継サーバー。Secretキーはここだけで使います。

## ひとりで遊ぶ
`index.html` をブラウザで開くだけ。サーバーは不要です。

## オンライン対戦
1. Node.js 18 以上を用意する
2. Secretキーを環境変数に入れて起動する
   ```
   SERBANK_SECRET=sk_あなたのSecretキー node server.js
   ```
3. ブラウザで `http://localhost:3000` を開く (中継サーバーURL欄に自動で入ります)
4. 友だちと同じ「ルーム名」を入れて「オンラインであそぶ」

インターネット越しに対戦する場合は、`server.js` を Render などに置いて
(環境変数 `SERBANK_SECRET` を設定)、そのURLを「中継サーバーのURL」欄に入れてください。

## しくみ
- ダメージ計算はサーバー側 (`WEAPONS` 表) で行い、SerBANK の `room_ルーム名` に保存します。
- 各プレイヤーは Publicキーの WebSocket でルームの更新をリアルタイムに受け取ります。
- ルールは、コンボ(連続正解)でダメージ最大2倍、いちばんダメージを与えた人の勝ち、トドメを刺した人も表示されます。
